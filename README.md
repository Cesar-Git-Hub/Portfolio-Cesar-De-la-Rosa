# Portafolio Web - Cesar De la Rosa

Este proyecto es un portafolio personal diseñado para mostrar mis habilidades, proyectos y experiencia profesional en desarrollo web y análisis de datos.

## 🚀 Características
- Diseño **responsivo** para dispositivos móviles, tablet y escritorio.
- Navegación clara y accesible.
- Secciones principales: Sobre mí, Proyectos, Contacto.
- Implementación de **modo claro/oscuro**.
- Código estructurado con **HTML semántico**, CSS modular y JavaScript interactivo.
